# 这些规则是怎么来的

这套流程不是凭空设计的。它来自两次真实的"人 + AI 做技术汇报"的完整过程，一次迭代了十六个版本。下面是其中反复出现的失败方式，以及每一种对应到流程里的哪条规则。

读这份文档比读规则本身更有用：规则会过时，失败方式不会。

## 讲什么

| 发生了什么 | 根因 | 现在的规则 |
|---|---|---|
| 大纲列了二十页，被评价"啰嗦、抓不住重点" | AI 把手头所有材料都排了进去，没有先问"核心论点是什么" | 分镜每页只有一句 `point`；写不出来就删（S2） |
| 做完十几页后，反馈是"没有把我想表达的东西讲清楚" | 一直在改表现，没回头对齐每页要讲的那件事 | 意见分类：要讲的东西不对 → 回分镜，不在 HTML 上打补丁（S5） |
| 最后靠一张"每页该讲清楚的点 / 现在的问题 / 你的意见"的表才收敛 | 这张表本该是第一步 | 这张表就是 `storyboard.md`，而且先于任何 HTML |
| 加了文献综述页、总结页、要求清单页，被评价"画蛇添足" | 套用了汇报的通用模板 | 没有模板页。每页必须有自己的 `point` |

## 用什么材料

| 发生了什么 | 根因 | 现在的规则 |
|---|---|---|
| 用仓库里的旧数据统计出一组时间数字，人说"不是这个，你没认真看" | AI 自己找的数据顶替了人要给的数据 | 人指定的来源优先；拿不到就留占位（S1） |
| 人说"这张图对话里就有"，AI 没找到就先用了别的 | 没把"找不到"当成需要上报的事 | 缺的材料登记为"缺"，在 deck 上显示成占位框 |
| 编译器对比表里写错了一个算法，人说"别想当然" | 凭印象写了没读过的论文 | `data-unverified` 标记；统一检索阶段逐条对回原文 |
| 两份数据对同一个量给出不同的值 | — | 冲突时并排列出、停下来问 |
| 图上的点是从图片上按像素读出来的 | 拿不到原始数据 | 可以，但必须标 `data-derived` 并在交付时说明 |

## 怎么表现

| 发生了什么 | 根因 | 现在的规则 |
|---|---|---|
| "文字太多、太叙事化" | 把讲稿写在了页面上 | 正文词数预算；解释性段落报警 |
| "小字大家看不见""图注放大一点" | 按屏幕阅读的尺度排版 | 字号下限按舞台像素检查，SVG 也算 |
| "本该手绘的图没画" | 用占位框和文字描述代替了图 | 能画就画；占位只给真正在等材料的位置 |
| "这条那么尖的曲线能看出来什么" | 选图时没问"这张图让人看到什么" | 设计原则：图是论据 |
| "那么多可调的东西完全看不懂在干什么" | 交互为了交互 | 每个控件要回答"它让听众多看到了什么" |
| 坐标轴用了自己起的代号 | — | 坐标轴写含义和单位，用听众的记号 |
| 页面下面一大块留白 | — | 截图逐页看 |
| 窗口缩小后版面乱掉 | 没有统一的缩放模型 | 固定舞台 + 整体缩放 + 窄屏纵向模式，由内核负责 |
| 公式显示出错 | 依赖运行时公式库 | Unicode 或 MathML |

## 怎么协作

| 发生了什么 | 根因 | 现在的规则 |
|---|---|---|
| 人说"P5 没必要"，AI 删错了页 | 页码在十几个版本里一直在变 | 稳定的语义 id；删除前用 id 复述 |
| 标题先被要求写成结论句，后来又嫌"太诡异"改回短语 | 口径没在一开始定下来 | 标题风格是 brief 里的一项，不是内核的规定 |
| 页脚署名、章节标签、灰色小标签被要求全部删掉 | AI 默认加了"专业感"的装饰 | 页面上放什么由 brief 决定；默认不加 |
| 幻灯片是英文，但人要求对话用中文 | 把两种语言当成一回事 | brief 里分开写 |
| 嵌入的回放在托管页面上打不开（iframe 空白、fetch 失败） | 托管环境拦截 iframe 和跨文件请求 | 单文件、全内联是硬规则 |
| 拖滑块的时候翻了页 | — | 交互区声明 + 键位约定，由内核负责 |
| AI 说"改好了"，其实没截图看过 | — | 自检三件事；没做的要明说 |
| AI 的若干推断散落在长回复里 | — | `open` 项自动汇总成"需要你确认的"清单 |

## 做对了的

同一批过程里也有被明确认可的做法，流程把它们固定了下来：

- 先出大纲，问清楚三个决定走向的问题，再动手。
- 给数据和演示**预留位置**，先把结构和视觉调好，数据到了再统一填。
- 人给的可视化（回放、报告）被**改造成 deck 自己的风格**再嵌入，而不是原样贴进去。
- 每次交付都列出"有几处是我加的或推断的，你看一下"。
- 一个统一的评价坐标贯穿全篇，让每一页都落在同一张图上。
